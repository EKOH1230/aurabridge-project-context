# AuraBridge 网站需求草案

## 当前目标与展示范围

- 先制作一个供 Joe 内部审阅和展示的网站原型，暂时在本地运行，不需要域名，也不向公众开放。
- 网站只服务 B2B 访客和潜在合作伙伴，不做消费者零售。
- 首期只做英文版；是否本地化为法语、中文或其他语言，之后由用户决定。
- 产品组合尚未确定。Products 页面可以保留空白结构或写清楚“产品内容待确认”的占位，不展示猜测的产品。

## 目标访客

- 网站先平均面向所有 B2B 合作伙伴，包括品牌方、进口商、分销商及专业渠道；当前不设优先客群。

- 零售消费者不是本网站的目标受众。

## 初始页面建议

以下是用于原型的页面结构，内容要符合现阶段可核实的信息：

| 页面 | 初步内容 |
|---|---|
| Home | AuraBridge 简介、B2B 合作定位、亚洲与欧洲市场连接能力、合作联系入口 |
| About | 公司背景、使命与价值观；集团关系做成可开关模块，默认隐藏，展示时由用户决定是否启用 |
| Products | 保留页面骨架，标注产品组合正在确定；暂不列具体产品 |
| Partnerships | 用保守文字介绍潜在合作形式；只展示已确认且实际可提供的服务 |
| Contact | 先展示非功能性占位/联系 CTA；没有用户确认的联系方式前不编造邮箱、地址或电话 |

## 设计方向

- 主色：蓝、白、黑；红色只作少量强调色。
- 当前使用 `references/AuraBridge_临时Logo_2026-09-28.jpg` 作为临时标志，直至最终 Logo 确认。用户说明 Logo 商标申请已受理；“受理”不能表述成“注册成功”。
- 网站观感应专业、清晰、可信，适合医疗美容与健康领域；优先移动端可读性和可访问性。
- 避免用红色营造治疗效果、紧急促销或夸大承诺的视觉语气。

## 内容与合规原则

- 不公开未经核实的产品性能、效果数据、客户 Logo、合作关系、认证、专利、销量或监管结论。
- 头皮液体涂抹设备属于曾讨论的硬件方向；不得将 AuraBridge 或供应商说成米诺地尔药品生产商，也不得暗示设备治疗脱发、促进吸收或增强药效。
- 英文内容计划由用户身边多位同学与 AI 协助检查语言和潜在合规问题。对医疗器械分类、法规责任、健康效果声称等高风险事项仍要用可靠资料核实，并在真实对外发布前考虑专业审核。
- 网站目前是内部演示原型，不连接真实表单、邮件、CRM、付款或分析工具。

## B2B 营销目标

把网站作为后续 B2B 获客和渠道推广的基础。营销计划需评估 TikTok、Instagram、Facebook、Google（搜索/SEO/广告等）和抖音等渠道，并可按目标市场补充适用渠道。规划时再明确各平台的受众、内容类型、语言、账号归属、预算、衡量指标和执行阶段；目前不代表已开设账号或批准投放。

## 暂缓决定的实现事项

域名之后再处理。当前原型优先采用简单、易运行、便于 Codex 修改的方案，不需要 CMS、数据库、用户账号、追踪分析或真实联系表单。原型可以由用户与 Codex 合作完成；将来要公开上线、配置域名/托管、管理个人数据或运营表单时，再根据实际复杂度决定是否请专业人员协助。
