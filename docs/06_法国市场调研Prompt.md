# 法国市场调研任务书

## 研究对象

为深圳景美瑞科技股份有限公司（名称及英文品牌仍需核实）调研其头皮液体涂抹设备进入法国市场的可行性。设备用于传递或涂布消费者已有液体；景美瑞不销售米诺地尔等生发药。

此前给另一 AI 的 Prompt 中列出 `https://www.szbetico.com/`、`https://www.kimairay.com/` 作为官网线索，可能出现 BETICO、Kimairay 等名称。研究开始时应访问网站并确认域名、产品、公司关系和更新时间，不可默认信息仍有效。

## 要回答的问题

1. 法国脱发及头皮护理用户的人群和可服务市场分别有多大？
2. 用户的脱发焦虑和付费意愿如何，按男女与年龄段区分？
3. 法国米诺地尔产品有哪些剂型、品牌、价格、购买渠道和自带涂布工具？
4. 消费者是否使用精油、头皮精华、安瓶、护理液？这些液体的实际涂抹方式是什么？
5. 评论、用户访谈和药房/沙龙访谈中，是否反复出现长发难以触达头皮、沾到头发、滴漏、控量、清洁麻烦等痛点？
6. 法国有哪些直接替代品和间接替代品？消费者是否会另买专用设备？
7. 滚珠、梳齿、定量/自动出液、防滴漏、可清洁、震动、EMS、红光等功能分别带来什么价值？
8. 设备宣传及销售在欧盟/法国可能涉及哪些产品分类、认证、标签、市场责任和广告限制？
9. 药房、电商、美发沙龙、诊所、分销商、OEM/ODM 各渠道的进入要求、利润和风险是什么？
10. 适合先测试的售价、试销规模、KPI、六个月和十二个月方案是什么？

## 研究边界

- 分开统计有脱发问题的人、主动买护理产品的人、使用液体护理的人、可能单独购买涂布设备的人。
- 米诺地尔药品的销售不代表涂布器的销量。
- 不预设欧洲消费者更喜欢精油；用法国本地证据验证。
- 不将产品包装中的自带滴管/喷头忽略；比较后说明独立设备有什么增量价值。
- 不把红光帽、激光梳等直接等同于液体涂布器。
- 区分用户证据、品牌宣传、专家意见、计算估算及未知信息。
- 不作“治疗脱发”“促进吸收”“增强药效”等无证据结论。
- “CE”“MDR”“普通消费电子”等判断必须依据产品预期用途、功能、宣传和官方/权威来源，不能只看电商页面。
- 法规部分优先查 European Commission、EUR-Lex、ANSM、DGCCRF、法国政府及权威标准来源。
- 法国市场数字注明年份、地域、单位、算法与来源；数据缺失时明确写无可靠公开数据。

## 竞品比较字段

品牌、产品名、国家、直接/间接替代类型、是否自动出液/定量、滚珠或梳齿、震动/EMS/光功能、兼容液体、价格、渠道、评价数量/评分、卖点、差评、相对差异和来源链接。目标至少15个有实际销售证据的产品；达不到时解释搜索范围和缺口。

## 市场进入方案

比较三个候选定位：
- 米诺地尔配套涂布器；
- 头皮精华涂布工具；
- 多用途头皮液体涂布设备。

给出适合用户、法语/英语类别名称、价格测试、渠道次序、六个月与十二个月试销计划、退出条件、风险、未知假设及下一步三项行动。最后明确 Go / Conditional Go / No-Go，并按用户需求、痛点、规模、竞争、差异化、法规、渠道、定价、教育成本、供应链匹配度给出0–100分，同时解释方法。评分不应伪装成历史事实。

## 输出大纲

执行摘要；公司与产品核实；用户细分；脱发及头皮护理习惯；米诺药品及自带工具；评论与访谈证据；竞品；功能价值；法规/宣传风险；渠道；定价和利润假设；定位与命名；进入计划；风险；假设和补资料清单；结论；来源链接。

## 优先索取的公司资料

产品目录、规格书、适配液体与材料兼容性、清洁说明、剂量与公差、测试数据、电池/充电参数、真实认证及证书范围、专利权利人及有效状态、产能、MOQ、成本、交期、质保/退货、已出口市场及允许公开的客户案例。
