# 技术选择与自助边界

## 现在的原型

当前目标只是本地展示的英文 B2B 公司介绍网站，不对外开放、不用域名、不连接表单、邮件、支付、客户管理或分析服务。它适合由用户在 Codex 协助下完成：Codex 可以解释改动、页面结构和本地预览方法，用户不必先聘请开发人员。

建议原型阶段保持轻量：沿用已有代码库和依赖；如果没有代码库，再选择简单的静态网站结构。当前不需要数据库、CMS、用户登录或后台管理。

## 之后可能自行完成的工作

- 修改英文介绍、颜色、图片和静态页面。
- 本地预览并向 Joe 展示。
- 内容确定后，再按说明配置域名和托管，或先创建受密码保护的预览。

## 适合请人协助的阶段

- 需要正式品牌识别/Logo矢量稿和完整设计系统时，可找设计师。
- 公开涉及医疗器械身份、效果声称、隐私、Cookie 或跨境数据时，找合适的法规/隐私专业人员审核。
- 网站要收集真实客户信息、接 CRM/邮件系统、支持内容团队持续编辑、处理安全或高流量要求时，再考虑专业开发或托管支持。

这些是后续选择，不是当前原型的前置条件。是否聘请他人可在展示原型、确认内容后再判断。
