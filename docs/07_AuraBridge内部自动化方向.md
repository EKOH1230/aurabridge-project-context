# AuraBridge 内部自动化方向

AuraBridge 可逐步探索内部重复流程的自动化。Joe 已确认当前资料包讨论 AuraBridge 自身的流程；Bright Bridge 集团其他业务的整体自动化由用户在单独聊天中讨论。

## 当前候选流程

- 邮件问候与跟进草稿。
- 网站、营销和产品内容的审核辅助，包括语言、事实依据及潜在法规风险提示。
- 财务资料的识别、归档、字段整理和异常标记，由授权人员核对后处理。

试点应从低风险、重复率高、容易人工复核的流程开始。AI/自动化不应直接付款、修改银行资料、发送未经确认的对外邮件或完成最终记账。具体系统、数据权限和审批流程待用户进一步说明。
