### 当时助手

可以做，而且你最适合扮演的不是“程序员”，而是Joe公司的“流程自动化负责人”：先找出他每天重复做、耗时间但不需要他本人判断的工作，再用自动化把这些工作移走。

我建议不要一上来更换公司系统，先围绕旧系统做一层“外挂式自动化”。

### 最值得先做的两个试点

#### 1. 财务录入自动化

现在可能是：

> 收到发票、订单或银行流水 → 财务/Joe查看 → 手动复制金额、客户、日期 → 输入旧系统

可以改成：

> 邮件/PDF/Excel/扫描件 → 自动识别字段 → 检查重复和异常 → 生成导入表 → 财务确认 → 写入旧系统

具体分三种情况：

- 旧系统支持Excel导入：最简单，自动生成符合格式的Excel。
- 旧系统有API：可以直接连接，但需要系统供应商配合。
- 什么接口都没有：用RPA模拟人工点击、复制和输入，例如影刀RPA、UiBot或Power Automate Desktop。

第一阶段不要让机器自动记账或付款，只做到“自动预填，财务点击确认”。这样风险低很多。

举个假设：每天20笔录入，每笔节省5分钟，一个月大约能省36小时。实际值需要你观察后计算。

#### 2. Joe的邮件助手

不要一开始让AI自动发邮件，而是先让它：

- 自动区分客户询价、供应商、物流、财务、内部邮件。
- 每天早晚生成重要邮件摘要。
- 标出需要Joe亲自决定的邮件。
- 根据以前的邮件风格生成中英日文回复草稿。
- 自动带入报价、交期、产品型号等信息。
- Joe只需要修改、确认和发送。

因为Joe用的是网易企业邮箱，需要先确认是否能通过IMAP、SMTP或其他接口连接。如果不能，也可以用邮件转发、浏览器RPA或本地助手完成。

### 制造和外贸公司还可以自动化什么

| 场景 | 可以自动化的内容 | 优先级 |
|---|---|---:|
| 报价 | 根据产品、数量、客户地区自动生成报价单 | 高 |
| 外贸单据 | 同一笔订单生成PI、合同、装箱单、出货资料 | 高 |
| 应收账款 | 到期提醒、逾期客户清单、催款邮件草稿 | 高 |
| 订单跟进 | 自动汇总打样、生产、验货、出货状态 | 高 |
| 采购 | 根据库存和订单生成采购建议、询价草稿 | 中 |
| 文件管理 | 合同、发票、产品资料自动命名和归档 | 中 |
| 经营报表 | 每天显示订单额、回款、欠款、库存、交期风险 | 中 |
| 会议 | 录音转文字、提取责任人和截止日期 | 中 |
| 产品资料 | 自动整理规格书、认证、图片和客户常见问题 | 中 |

其中“报价—订单—生产—出货—回款”应该尽量使用同一份订单数据，避免每到一个环节就重新手敲一遍。

### 你接下来30天可以这样做

**第一周：记录流程**

跟着Joe和财务人员工作两三天，记录：

- 做了什么；
- 一天/一周做几次；
- 每次需要多久；
- 输入来自哪里；
- 最后录入什么系统；
- 哪一步最容易出错；
- 哪一步必须由老板判断。

**第二周：只选一个试点**

建议优先选：

> 发票或订单附件 → 自动提取信息 → 生成旧系统导入表 → 人工确认

它规则明确、效果容易计算，也不会直接改变核心账务。

**第三周：做一个最小版本**

先只支持一种文件、一家公司主体、10个左右固定字段，不追求一次覆盖所有情况。

**第四周：并行测试**

人工流程继续保留，让自动化同时跑20–50笔，对比：

- 每笔耗时；
- 识别准确率；
- 修改次数；
- 有没有重复或漏录；
- 每月预计节省多少小时。

准确后再扩大，不要直接全公司上线。

### 三条安全底线

- AI不能直接付款、修改银行账号或最终记账。
- 对外邮件先由人确认，尤其是报价、合同、交期和投诉。
- 所有自动化都要保留操作记录、权限控制和异常提醒。
